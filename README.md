# Лабораторна робота №2 — сортування Бетчера (Haskell, GHC -threaded)

Багатопотоковий додаток, що реалізує обмінне сортування зі злиттям Бетчера
(Batcher odd-even merge sort) для заданого масиву за допомогою k потоків
(k вводиться з клавіатури).

## Як працює

- Масив доповнюється до довжини, що є степенем двійки (значеннями `maxBound`,
  які після сортування відкидаються), тому можна вводити масив будь-якої довжини.
- `batcherSort k` ділить масив навпіл і ділить потоки між половинами
  (`k/2` і `k - k/2`), доки на гілку не залишиться один потік.
  Отже, масив розбивається рівно на k частин, кожна сортується у своєму потоці.
- `oddEvenMerge k` зливає відсортовані половини: злиття парних і непарних
  позицій — незалежні задачі, тому вони теж виконуються паралельно,
  після чого застосовуються компаратори (обмін сусідніх пар).
- Паралельність — через `rpar`/`rseq` (пакет `parallel`), кількість потоків
  виконання задається `setNumCapabilities k`.
- Програма вимірює час для 1 потоку та для k потоків, виводить прискорення
  і перевіряє результат (порівнянням з `Data.List.sort`).

## Запуск

```
cabal build
cabal run batcher-sort
```

Приклад:

```
=== Batcher Odd-Even Merge Sort ===
CPU cores available: 8
Choose input: 1 - enter array manually, 2 - generate random array
1
Enter array elements separated by spaces:
5 3 9 1 7 2
Enter number of threads (k):
4
```

Щоб побачити прискорення, оберіть режим `2` і розмір масиву від 100000.
